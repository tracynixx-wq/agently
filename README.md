# Личный агент в Telegram

Пишешь команду текстом в «Избранное», агент сам пересылает медиа.

## Запуск
1. `my.telegram.org` → API development tools → получи `API_ID` и `API_HASH`.
2. Ключ Gemini (бесплатный): aistudio.google.com → Get API key → `GEMINI_API_KEY`.
3. `pip install -r requirements.txt` и `python make_session.py` → получишь `SESSION_STRING`.
4. На хостинге задай переменные: `API_ID`, `API_HASH`, `SESSION_STRING`, `GEMINI_API_KEY`.
5. Запуск: `python userbot.py`.

## Примеры команд (в «Избранное»)
- «пересылай видео из канала Новости в группу Работа в раздел Видео»
- «покажи правила»
- «удали правило 2»
- «перешли последние 30 фото из канала Архив в группу Работа раздел Фото»

Группа-приёмник должна быть форумом (включены темы). Если раздела нет, агент создаст его сам.

## Если код входа не приходит
Он приходит не по SMS, а в само приложение Telegram, в чат «Telegram» (с галочкой). Не пересылай и не показывай его никому: Telegram тогда блокирует вход. Если не пришёл, подожди пару минут и попробуй снова, не делая много попыток подряд.
